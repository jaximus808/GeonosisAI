# Wordmark

The GeonosisAI name set in Big Shoulders Stencil 800, uppercase, with "AI" in `melt`.

- Markup: `<span class="gx-wordmark">Geonosis<b>AI</b></span>`. The source text keeps the real casing and CSS uppercases it, so screen readers say "GeonosisAI".
- Sizes: `gx-wordmark` (28px) in the desktop header, `gx-wordmark-sm` (20px) on phone pages, `gx-wordmark-hero` (72px) on the demo title screen and the report cover.
- The optional descriptor "Robot deployment foundry" sits to the right in `gx-descriptor`, never underneath.
- Leave at least the cap height of clear space on every side.
- Don't outline it, add a gradient, set it in another face, rotate it, or put droid art next to it. Don't make the whole name orange.
- There is no symbol mark yet. For a favicon, use a `melt` square with a stencil "G" in `on-melt`.
